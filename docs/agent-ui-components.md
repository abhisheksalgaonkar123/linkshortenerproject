# UI Component Instructions

- Use shadcn ui for all UI elements in this app.
- Do not create custom UI components when a shadcn ui component can be used.
- Prefer composing existing shadcn ui primitives over building new component abstractions.
- Keep styling changes within the established Tailwind + shadcn patterns already used in the repository.
- If a requested UI element is not available yet, add it through the shadcn ui workflow instead of hand-rolling a custom component.
